# /profile — 내 프로필 채우기

`/rank` 와 `/apply` 는 프로필을 근거로 채점하고 자소서를 씁니다. 프로필이 비어 있으면
둘 다 쓸모가 없으므로 먼저 이걸로 채웁니다. 앱의 **내 프로필** 탭과 같은 데이터입니다.

## 1. 현재 상태 확인

```bash
python jobctl.py profile
```

`empty` 가 false 면 무엇이 채워져 있고 무엇이 비었는지 짧게 보여주고, 보완할 항목만 묻습니다.

## 2. 재료 받기

사용자가 이력서·자소서 파일이나 텍스트를 주면 거기서 뽑습니다. 없으면 아래를 **한 번에 2~3개씩** 묻습니다
(한꺼번에 다 묻지 말 것). 모르면 비워 두고 넘어갑니다.

| 항목 (키) | 물어볼 것 |
| --- | --- |
| `career` | 다닌 회사·기간·맡은 일 (생산직이면 라인/설비/교대 여부까지) |
| `education` | 최종 학력·전공 |
| `certificates` | 자격증·면허 (지게차, 전기기능사, 운전면허 등) |
| `skills` | 다룰 수 있는 설비·도구·프로그램 (PLC, CNC, 엑셀 등) |
| `desired_role` | 원하는 직무·지역·근무형태 (교대 가능 여부, 기숙사 필요 여부) |
| `strengths` | 스스로 생각하는 강점 |
| `episodes` | 자소서에 쓸 경험 2~4개: `title`, `situation`, `action`, `result` |

`episodes` 가 자소서의 재료입니다. "열심히 했다" 수준이면 한 번 더 물어 **숫자나 구체적 장면**을 받아내세요
(불량률, 처리량, 해결한 고장 등). 사용자가 말하지 않은 숫자를 추측해 넣으면 안 됩니다.

## 3. 저장

받은 항목만 JSON으로 저장합니다. 보낸 항목만 덮어쓰고 나머지는 그대로 둡니다.
한글이 깨지지 않게 파일로 넘깁니다.

```bash
python jobctl.py save-profile --file <임시파일>.json
```

저장 후 `python jobctl.py profile` 로 다시 읽어 확인하고, 아직 빈 항목을 한 줄로 알려줍니다.
