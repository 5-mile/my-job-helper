# /rank — 공고 일괄 채점 → 지원할 곳 추리기

사람인에서 공고를 모아 내 프로필 기준으로 한꺼번에 채점하고, 지원할 만한 곳만 추립니다.
**1차 선별용 점수**입니다. 깊은 판단과 자소서는 `/apply` 에서 합니다.

(평가 틀은 [ai-job-search](https://github.com/MadsLorentzen/ai-job-search) 의 Job Evaluation Framework, MIT 를 한국 생산·제조 채용에 맞게 줄인 것입니다.)

## 0. 입력 해석 (`$ARGUMENTS`)

- 비어 있음 → 프로필의 `desired_role` 에서 검색어 1~3개를 뽑는다
- `생산 품질` 처럼 단어 → 그 검색어로
- `보관함` → 새로 수집하지 않고 보관함 공고를 채점
- `--top N` (기본 5), `--pages N` (기본 2)

## 1. 프로필 읽기 (한 번만)

```bash
python jobctl.py profile
```

`empty` 가 true 면 멈추고 "`/profile` 로 먼저 프로필을 채워주세요" 라고 안내한다. 빈 프로필로 채점하면 점수가 전부 지어낸 것이 된다.

## 2. 후보 모으기

```bash
python jobctl.py search <검색어들> --pages 2
# 또는
python jobctl.py saved
```

목록 단계에서 이미 걸러지는 것은 **본문을 열지 않고** 바로 탈락시킨다 (토큰 절약):
`desired_role` 의 지역과 동떨어진 곳, 학력·경력 조건이 명백히 안 맞는 곳, 마감 지난 곳.
남은 것 중 최대 15개만 다음 단계로 넘기고, 나머지는 "보류 N건" 으로 숫자만 알린다.

## 3. 본문 읽고 채점

후보마다 본문을 읽는다:

```bash
python jobctl.py detail <link>
```

`IMAGE_ONLY` 가 나오면 본문이 통이미지인 공고다. **목록 정보만으로 점수를 지어내지 말고** "본문 확인 불가" 로 따로 분류한다.

후보가 6개 이상이면 Agent 도구로 5개씩 나눠 병렬로 처리해도 된다. 그때는 프로필 요약과 아래 기준표를 **프롬프트에 직접 넣어** 넘긴다 (에이전트가 다시 읽게 하지 말 것).

### 3-1. 필수 조건 — 점수 매기기 전에 먼저

하나라도 걸리면 **채점하지 않고 탈락**. 탈락시킬 때는 공고의 해당 문장을 그대로 인용한다.

| 확인 | 탈락 조건 |
| --- | --- |
| 자격증·면허 | 공고가 **필수**로 요구하는데 프로필 `certificates` 에 없음 ("우대"는 탈락 아님) |
| 학력 | 명시된 학력 범위 밖 (예: "4년제 졸업자 지원 불가") |
| 경력 | 최소 경력 연차를 명백히 못 채움 |
| 근무 형태 | `desired_role` 에 "교대 불가" 등이 있는데 교대 필수 |

애매하면 탈락시키지 말고 **⚠️ 확인 필요** 로 표시하고 채점은 진행한다. 판단은 사람이 한다.

### 3-2. 점수 (각 0~100)

| 항목 | 가중치 | 보는 것 |
| --- | --- | --- |
| 직무 기술 | 30% | 하는 일·다루는 설비가 `skills`, `certificates` 와 맞는가 |
| 경력 | 25% | 직함이 아니라 **실제로 하던 일**이 비슷한가 |
| 근무 조건 | 15% | 교대·고용형태·급여·기숙사가 `desired_role` 과 맞는가 |
| 커리어 방향 | 30% | 원하는 쪽으로 가는 자리인가 |

총점 = 가중 평균. **75+ 강력 추천 / 60~74 추천 / 45~59 고민 / 45 미만 패스**.

근거는 프로필과 공고 본문에 **실제로 있는 내용**으로만 댄다.

## 4. 결과

상위 `--top` 개를 표로:

| 순위 | 점수 | 회사 / 공고 | 마감 | 맞는 점 | 걸리는 점 |

그 아래에 한 줄씩: 탈락 N건(사유별 개수), 본문 확인 불가 N건, 보류 N건.

마지막으로 **"보관함에 넣을 번호를 알려주세요"** 라고 묻는다. 사용자가 고른 것만:

```bash
python jobctl.py save --file <임시파일>.json   # search 결과의 공고 객체 그대로
```

저장하면 앱 보관함에 바로 보인다. 이어서 `/apply <link>` 로 자소서를 쓸 수 있다고 알려준다.
